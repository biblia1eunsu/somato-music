# 소마토센서리 요가 · 클래스 음악

비비아요가앳홈의 소마토센서리 요가 수업을 위한 음악 플레이어입니다.
대기 음악 → 오프닝 15분 → 호흡 3분 → 메인 플로우 30분 → 컴다운 30분 → 사바아사나(5·10분) →
다시 대기 음악으로 한 화면에서 이어집니다.

전체 타임라인은 **88분(90분 수업)** 기준입니다. **60분 수업**에서는 수업 화면 위쪽의
구간 타임라인 칩(오프닝 · 호흡 · 메인 플로우 · 컴다운 · 사바아사나)을 눌러 필요한 구간으로
바로 넘어가거나, `◀|` `|▶` 로 앞뒤 구간을 오가며 쓰시면 됩니다.

## 선곡 관리 (한 페이지)

상단의 **선곡 관리** 버튼을 누르면 파트별 전체 곡이 한 페이지에 펼쳐집니다.

- **▶ 미리듣기 · ■ 정지** — 그 자리에서 실제 유튜브 음원을 들어봅니다. 미리듣기는 전용
  플레이어 하나만 쓰고, 시작할 때 수업·대기 음악을 멈추므로 **소리가 겹치지 않습니다**.
  정지하거나 한 곡이 끝나면 원래 음악으로 돌아옵니다.
- **즉시 시작 (v28)** — 앱을 열 때 미리듣기 플레이어와 첫 대기곡을 미리 준비해 두고,
  `▶` 를 누른 그 순간(같은 제스처 안)에 `loadVideoById` + `playVideo` 를 부릅니다.
  이미 열려 있던 곡은 다시 불러오지 않아 광고를 새로 요청하지 않습니다.
  상태 표시는 `여는 중 → 미리듣기` 로 0.15초 간격으로 확인해 바로 바뀝니다.
- **광고가 나오면 플레이어가 보입니다 (v28)** — `▶` 를 누르면 20초 동안 화면 아래에
  작은 유튜브 플레이어가 함께 떠서, 유튜브 프리롤 광고가 나와도 그 자리에서
  **건너뛰기**나 재생 버튼을 직접 누를 수 있습니다. 곡이 바로 나오면 20초 뒤 사라지고,
  1.2초가 지나도 소리가 시작되지 않으면(광고·자동재생 차단) 계속 떠 있습니다.
- **✕ 빼기** — 뺀 곡은 수업 재생 목록에서 완전히 빠집니다(`localStorage` 저장).
  파트 아래 **뺀 곡**에서 **되돌리기** 할 수 있고, 마지막 한 곡은 수업이 비지 않도록 뺄 수 없습니다.
- **↑ 맨 앞으로** — 대기 음악처럼 첫 곡이 중요한 파트에서 그 곡을 첫 곡으로 고정합니다.
  고정한 곡은 정한 순서대로 먼저 재생되고 그 뒤만 섞입니다. 한 번 더 누르면 지정이 풀립니다.
- **＋ 유튜브 링크로 곡 추가** — 파트마다 직접 링크를 붙여 넣어 추가합니다(이 기기에만 저장).
- 파트를 모두 비우거나 처음 상태로 돌리려면 페이지 아래의 **뺀 곡 모두 되돌리기**,
  **첫 곡 지정 모두 해제**, 설정의 **추가한 곡 초기화**를 쓰시면 됩니다.

## 부가 기능

- **구간 타임라인 · 구간 이동** — 상단 칩과 `◀|` `|▶` 로 90분 타임라인 어디로든 이동
- **`다른 곡` 버튼** — 지금 흐르는 음악 카드 안에 있어 수업 중 한 손으로 바로 누를 수 있습니다.
  누르면 같은 구간의 다음 곡으로 **3.5초 페이드아웃 → 3.5초 페이드인**으로 넘어갑니다
- **볼륨** — 기본 볼륨을 42%로 낮추고 **대기 음악은 설정 볼륨의 68%** 로 한 단계 더 은은하게 깔립니다
  (이전 버전에서 62%로 저장된 기기는 한 번만 자동으로 낮춰 맞춥니다)
- **모든 전환이 3.5초 크로스페이드** — 대기 음악 → 수업 시작, 구간 자동/수동 전환, 테마·모드 전환,
  `다른 곡`, 이전·다음 구간 버튼까지 기존 음악이 약 3.5초에 걸쳐 줄어들고 새 음악이 0에서
  3.5초 동안 천천히 올라옵니다 (유튜브는 S-커브 볼륨 램프, 내장 사운드는 Web Audio 램프)
- **사바아사나 5분 / 10분** — 설정 시트와 수업 중 사바아사나 패널에서 바꿉니다. 수업 중에 바꿔도
  타임라인이 바로 맞춰집니다
- **바디스캔 명상 버튼** — 사바아사나 패널과 수업 컨트롤 칩에서 켜고 끕니다. 가사·멜로디 없는
  초저자극 드론과 숨결 패드(내장) 또는 바디스캔 앰비언트 풀(유튜브)이 흐릅니다
- **잠금 화면 · 이어폰 조작 (Media Session API)** — 화면이 꺼져도 재생·정지·곡 넘기기가 됩니다.
  내장 사운드는 MediaStream → `<audio>` 연결로 iOS 사파리에서 화면이 꺼진 뒤에도 최대한 이어집니다
- 구간 전환 시 볼륨 페이드, 수동 구간 점프 · 일시정지 · 남은 시간 확인
- 사바아사나 진입·종료 시 은은한 **싱잉볼 타종** (On/Off)
- 수업 중 화면 꺼짐 방지 (**Wake Lock API**, On/Off · 화면으로 돌아오면 자동 재획득)
- 라이트(킨포크 · 이솝풍 웜 뉴트럴) / 다크 스튜디오 모드
- PWA — 홈 화면에 추가하면 앱처럼 열리고, 앱 셸은 오프라인 캐시

## 음원 재생 구조

1. **YouTube IFrame Player API** 로 구간별 큐를 순환 재생합니다. 큐의 모든 영상은 실제
   IFrame 플레이어로 임베드 검사를 통과한 ID만 수록했습니다(`tools/verify5.html` ·
   `verify6.html` · `verify7.html` · `verify8.html` · `verify9.html`). 1시간짜리 모음 · 저음질 비공식
   업로드는 모두 걷어냈습니다.
2. **소리의 주인은 언제나 하나입니다 (v24)** — `owner` 가 `youtube` 이면 내장 사운드
   두 덱을 즉시 완전 정지(gain 0 + stop)하고, `builtin` 이면 유튜브를 `mute()` +
   `stopVideo()` 합니다. 유튜브 볼륨을 올리는 모든 경로는 `owner === 'youtube'` 일 때만
   열리므로, 늦게 도착한 타이머·콜백이 소리를 겹치게 만들 수 없습니다.
   앱 안의 내장 사운드 출력은 `musicPeak()`(유튜브 재생 중 0)로 실측 확인합니다.
   미리듣기는 이 구조 위에 **전용 플레이어 하나**(`#ytPreviewPlayer`)를 더 둔 것으로,
   시작할 때 본 재생을 멈추고 끝나면 원래 구간으로 돌려놓기 때문에 곡이 겹치지 않습니다.
3. 시작 지연을 줄이는 장치(v28): 앱을 열면 **미리듣기 플레이어를 함께 만들고**, 수업 첫 곡(오프닝 1번)을
   **음소거로 미리 열어** 프리롤 광고를 수업 전에 소리 없이 소진해 둡니다(v28d). 그래서 대기 시간이
   20초만 있어도 `수업 시작`을 누른 순간 광고 없이 그 곡이 바로 흐릅니다(같은 영상은
   `loadVideoById` 대신 `playVideo`/`seekTo` 로 이어 재생). 새 곡은 **누른 그 제스처 안에서 곧바로**
   불러옵니다 — 예전처럼 3.5초 페이드를 기다렸다가 부르면 iOS 가 재생을 막았습니다(v28d).
   재생 판정은 `getPlayerState()` 가 -1로 남는 경우가 많아 **재생 시간 진행(`getCurrentTime() > 0.2`)**
   으로도 하고(0.15초 간격), 첫 시작은 0.6초, 곡 전환은 0.9초 만에 0→설정 볼륨으로 올라옵니다.
4. 유튜브 광고는 IFrame API가 광고 여부를 알려주지 않습니다. 실측하면 **광고가 흐르는 동안에도
   `getVideoData()` 가 본 영상의 ID·제목·길이를 그대로 돌려주고** `getPlayerState()` 만 -1로 남습니다.
   실측으로는 광고 중에도 `getPlayerState()` 가 1이 되고 재생 시간이 흐르기 때문에 **앱이 광고 여부를
   확실히 알 방법이 없습니다**(v28d에서 무음 유지 로직을 넣었다가 광고 사이에서 풀리는 것을 확인하고 걷어냈습니다).
   대신 수업 시작 전에 첫 곡을 미리 열어(음소거) 광고를 대기 시간에 흘려보내 두고(위 3),
   `수업 시작`·`대기 음악` 때 **작은 유튜브 화면을 잠깐 띄워** 그 자리에서 광고의 **건너뛰기**를
   누를 수 있게 합니다. 곡이 처음(0초 부근)부터 흐르면 2.5초 뒤, 그렇지 않으면 20초 뒤 사라집니다.
   광고가 남아 있는 곡을 만나면 화면 배지로 알리고, 어떤 경우에도 **내장 사운드를 겹쳐 켜지 않습니다.**
   (광고 없는 수업은 사운드 소스를 내장으로 두거나 YouTube Premium 로그인으로 쓰세요.)
5. 영상이 임베드 제한(Error 101/150/2/5)이거나 재생이 두 번 다시 시작되지 않으면(v28d),
   **유튜브 모드에서는 신시사이저 내장 사운드로 마음대로 넘어가지 않고** 같은 구간의 다음 곡을
   차례로 시도합니다. 그 구간의 곡이 모두 열리지 않을 때만 무음으로 두고 `YouTube 재생 불가`
   배지와 안내를 남깁니다 — 합성음은 은수 님이 직접 **내장 사운드** 칩을 눌렀을 때만 나옵니다.
6. 내장 엔진은 **하프 · 펠트 피아노 · 오르골의 뜯는 소리 + 3.2초 잔향**만 냅니다.
   지속 드론/패드 신스음과 높은 사인 지속음(shimmer)은 v4에서 모두 걷어냈습니다.
   싱잉볼 타종은 음악 게이트와 분리된 FX 버스라 유튜브 재생 중에도 사용자가 켰을 때만 울립니다.
7. 설정이나 수업 화면의 **유튜브·내장** 칩으로 언제든 전환할 수 있습니다.
