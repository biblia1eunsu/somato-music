# 소마토센서리 요가 · 클래스 음악

비비아요가앳홈의 60분 소마토센서리 요가 수업을 위한 음악 플레이어입니다.
수업 전 대기 음악부터 사바아사나, 수업 후 마무리까지 한 화면에서 이어집니다.

## 수업 흐름

| 구간 | 시간 | 내용 |
| --- | --- | --- |
| 오프닝 | 10분 | 호흡 · 그라운딩 (Deuter, Liquid Mind, Shambhala Spa 계열) |
| 피아노 브릿지 | 3·4·5분 선택 (기본 4분) | 이루마 「Kiss the Rain」·「River Flows in You」, 이정혁 「형을 위한 노래」 |
| 메인 플로우 | 31·30·29분 (브릿지 길이에 따라 자동 조정) | 플로우 테마 4종 |
| 컴다운 | 10분 | 심박을 가라앉히는 피아노 · 하프 |
| 사바아사나 | 5분 | 추천 풀 5종 + 오늘의 랜덤 추천 |
| 마무리 | 1분 | 조용한 패드, 수업 후 대기 음악으로 연결 |

전체 합계는 브릿지 길이와 무관하게 **60분**입니다.

싱잉볼 · 명상 / 보컬 힐링 / 자연의 밤 · 빗소리 / 하프 · 오르골 / 크리스마스 잔잔한 캐롤 /
**오늘의 랜덤 추천**(날짜에 따라 매일 다른 풀에서 곡이 골라집니다).

## 부가 기능

- 구간 전환 시 1.2~1.8초 볼륨 페이드 아웃 · 인, 수동 구간 점프 · 일시정지 · 남은 시간 확인
- 사바아사나 진입·종료 시 은은한 **싱잉볼 타종** (On/Off)
- 수업 중 화면 꺼짐 방지 (**Wake Lock API**, On/Off)
- 라이트(킨포크 · 이솝풍 웜 뉴트럴) / 다크 스튜디오 모드
- 유튜브 링크를 붙여넣어 구간별 곡 추가 · 저장 (`localStorage`, 이 기기에만)
- PWA — 홈 화면에 추가하면 앱처럼 열리고, 앱 셸은 오프라인 캐시

## 음원 재생 구조

1. **YouTube IFrame Player API** 로 구간별 큐를 순환 재생합니다. 큐의 모든 영상은 실제
   임베드 재생 테스트를 통과한 ID만 수록했습니다(`tools/verify.html`).
2. 영상이 임베드 제한(Error 101/150/2/5)이거나 네트워크가 끊기면, 같은 구간의
   **내장 힐링 사운드 엔진**(Web Audio API)으로 자동 전환합니다. 패드 · 펠트 피아노 ·
   하프 · 오르골 · 싱잉볼 · 빗소리 · 파도 · 밤 자연음을 실시간 합성하므로 음원 파일 없이도
   수업이 끊기지 않습니다.
3. 설정에서 **내장 사운드만** 모드로 고정할 수도 있습니다.
